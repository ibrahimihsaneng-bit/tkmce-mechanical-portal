# MECH TKMCE Focus Companion (Manifest V3)

A lightweight, privacy-respecting browser extension companion for the **MECH TKMCE 3.0 Engineering Learning Operating System**.

## Features
- **Short-form Video Interventions:** Pauses algorithmic feeds (`youtube.com/shorts` and `instagram.com/reels`) during active study hours.
- **Academic Allowlists:** Preserves unhindered access to institutional resources (`tkmce.ac.in`, `nptel.ac.in`, `ocw.mit.edu`).
- **Emergency Access:** Immediate, 1-click unblock capability directly on your device. Zero remote locks.

## Installation in Chrome, Edge, or Brave:
1. Open `chrome://extensions` (or `edge://extensions` in Microsoft Edge).
2. Enable the **Developer Mode** toggle in the top-right corner.
3. Click **Load Unpacked**.
4. Select this `extension` folder.
5. The extension is now active and synchronizes with your Focus Studio sessions!
