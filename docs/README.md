# MECH TKMCE beginner learning starter

This package is an independent static demonstration and content seed, not the source code of the deployed portal. Open index.html directly in a browser; no installation or network connection is required for the reader. For Vercel, deploy this folder as a static site only on a separate preview project. For the existing website, use MASTER_UPGRADE_PROMPT.md and merge the JSON and original SVG files into the existing framework after backing up. Do not replace the live project blindly.

Included: semester course-slot catalog S1–S8; four foundation lessons; five introductory draft chapters for 24MET401; search, semester selection, lesson reader, local progress, print-to-PDF, references and diagrams. The catalog records source table course slots, including required non-ME courses for ME students and optional baskets. It is not a complete elective inventory, complete module extraction or full long-note library. The notes are original draft learning material, not faculty-approved or exhaustive. No PYQs are represented as official. No GATE exam-year syllabus mapping has been validated; GATE items are original foundation practice only. No production deployment performed.

Data: content/catalog.json, content/lessons.json, content/sources.json. data.js is generated from these files for offline file:// use; run python build_data.py after editing. Each lesson contains sections, worked examples, original practice, references, diagram path (if any), and status. Each catalog record has code, title, type and assessment where confirmed. Elective placeholders represent choice slots, not actual course IDs. All catalog entries are planning records; only 24MET401 has chapter drafts. The source PDF pages listed are physical page numbers (1-based). Some course codes/assessment cells in S6 appear misaligned in the source table; assessment not inferred for those entries. Check registration-specific options before publishing.

Use Print / Save PDF in the reader for a printable lesson. No PDF/DOCX files are included in this release. For long notes, expand each draft by syllabus topic with references and review, then export. Source links are external and need internet access. The public portal PDF was retrieved through the portal's syllabus link; some direct college PDF requests intermittently failed, so review against current college releases before production.
