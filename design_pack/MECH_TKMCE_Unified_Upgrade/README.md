# MECH TKMCE — Unified Focus Studio upgrade package

## Start here
1. Extract this archive into the existing website development workspace (not directly into production/public).
2. Open `design/index.html` in a browser. It is a navigable UI reference with sample data, not a live website or device blocker.
3. Review the desktop and mobile PNG screenshots in `design/previews/`.
4. Give Antigravity `MASTER_PROMPT.md` and access to the actual repository. Instruct it to follow the existing Focus Studio entry point, integrate the authorised Resource Manager, and use these reference screens.
5. Review `docs/RESOURCE_WORKFLOW.md`, `templates/` and `docs/ACCEPTANCE_CHECKLIST.md` before approving a preview deployment.

## Important boundaries
- All focus features live inside one existing Focus Studio, not independent top-level site pages. The upload area is an authorised administrative workflow, not a student focus tool.
- Screens contain illustrative data and are navigational mockups; buttons that would upload, publish, start a timer or enforce protection are demo controls. No real files are transmitted, no device is restricted, no production website is modified.
- The package does not contain the live repository, backend credentials, Android signing keys or actual catalogue data. The developer must inspect these before implementation. Course examples are illustrative until verified.
- Academic images must be sourced with reuse permission, not AI-generated. Included PNGs are screenshots of original HTML UI designs, not academic diagrams or copied Regain screens.
- Web-only protection is limited; native/extension functionality requires consent, platform support and real-device testing. Optional companions are not extra website dashboards.
